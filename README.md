# Final-project-

## Project Goal
Create a Java program that checks password strength and helps users improve their passwords.

## MVP Features
- Allow users to enter a password
- Check password length, character types, and patterns
- Rate passwords as weak, medium, or strong
- Give suggestions for stronger passwords

## Tech Stack
- Java
- Java standard library
- Git and GitHub
- Command-line interface

## Future Plans
- Password generator
- Common password dictionary
- Graphical user interface
